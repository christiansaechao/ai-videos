# ai-videos — Bright Side Faceless Channel

Scripts for the Bright Side–template faceless side-hustle channel. Two lanes,
one channel: the **Bright Side** scripts are the main line, and the
**Rocco / Buck / Murph** character scripts run alongside them.

The ShowTheReceipts work is a **separate product** and lives on its own branch
(`claude/showthereceipts-overview-krj50d`). It is deliberately not merged here.

## Lane 1 — Bright Side (main line)

`scripts/bright-side/`

| File | Contents | Count |
|---|---|---|
| `side-hustle-30-scripts.md` | Long-form scripts, ~5–6 min each, Bright Side formula | 30 |
| `side-hustle-300-shorts.md` | Shorts, 10 per niche across 30 niches, 2 × 10s blocks | 300 |
| `mobile-detailing-side-hustle.md` | Long-form pilot, ~10–11 min | 1 |
| `mobile-detailing-5min-blocks.md` | 5-min production cut of the pilot, 30 × 10s blocks | 1 |

Format: Kevin VO, burned Anton captions, vertical 9:16. `[VISUAL]` and
`(visual: …)` lines are shot cues for the AI video pipeline. Numbers are spelled
out for voicing.

## Production status

Every file here is a **written script**. Nothing tracks what has been produced or
posted — there are no status fields in any file. `rocco-master-schedule.md` lays
out 38 rounds over roughly two months, but which rounds have actually shipped is
not recorded anywhere in this repo.
