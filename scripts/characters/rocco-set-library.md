## SHOT ROLES (the fixed 4-beat shape)

| Shot | Role | Rule |
|---|---|---|
| **1** | HOOK | Absurd claim in the first 3 seconds. The number *is* the hook. |
| **2** | ESCALATE | Inflated number + **honesty slip** (the real, smaller truth escapes, then he covers). |
| **3** | SECRET | Lowers his voice, shares the "mechanism" — the tell that he's a fraud. |
| **4** | BUTTON | Three-verb CTA + signature **"…You're welcome."** |

## RECURRING SIGNATURE (never change)
- Closer: **"…You're welcome."**
- Three-verb CTA before it (*"Point. Spray. Retire."*)
- Filler: "Bro." / "BRO." / "Listen to me." / "That's just MATH."
- The **honesty slip** in shot 2 — this is the comment-bait engine.
- The background always quietly contradicts him.

## COMEDY GUARDRAIL
Rocco is always the fool and the fraud — the joke is *on* him. Where a bit touches
something genuinely shady (curbstoning, title fraud, expired stock), the BUTTON pays
it off with consequences catching up (cop lights, a DMV letter, a health inspector)
so it reads as cautionary parody, never a how-to.

## SCRIPT LINE FORMAT
Each shot is written as one line:

> **N ROLE** · **[SET]** frame/pose detail · *action prompt* · **"Dialogue."**

Dialogue stays ~80–90 characters (≈5–8s of speech).
